# Message composer

Messages can contain up to 120,000 characters. If a draft is longer, T3 Code keeps it in the
composer and shows how many characters need to be removed. Shorten the draft or split it into
multiple messages, then send again in the same thread.

## Agent Actions

Use the Agent Actions button beside the composer controls, or type `>` in the composer, to browse
the prompts and skills available from the connected environment. Choosing an action opens its
details and arguments. **Insert** adds an editable invocation to the composer; it does not send the
message.

When the connected environment supports workflow preferences, you can:

- pin prompts or skills for quick access;
- save explicitly entered prompt arguments as a named preset;
- update or remove a named preset from its prompt details.

Pins and presets are shared by projects connected to the same environment. Recent actions stay in
the current browser and are kept separate by environment, project, and thread. If a saved action is
temporarily missing from the live catalog, T3 Code reports it as unavailable instead of deleting
the saved reference.
